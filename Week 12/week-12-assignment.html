Step 3

Let’s say we want to create a map with facet_wrap() so we can see several Teacher race/ethnicity distribution at once. We will need to pivot our data so that all the race/ethnicity variables are in one column and their associated values are in another.

  1. Pivot the data below, where the columns we want to pivot are American Indian or Alaska Native:Unidentified.
tn_data_pivot <- tn_data %>% 
  pivot_longer(
    cols = 'american_indian_or_alaska_native':'unidentified',
    names_to = "race_ethnicity",
    values_to = "count"
  )
  1. Filter the data to at least two values of race/ethnicity for Teachers. Create a map with facet_wrap() for both of the race/ethnicities, where the shade of each district is the percentage of educators of that race/ethnicity. (Your plots may take a while, especially if it’s more than two).
tn_data_filter <- tn_data_pivot %>% 
  filter(race_ethnicity %in% c("white", "black_or_african_american"))

ggplot(data = tn_data_filter) +
  geom_sf(aes(fill = count, geometry = geometry)) +
  scale_fill_viridis_c(option = "magma", name = "Percent of Teachers") +
  facet_wrap(~ race_ethnicity)

Step 4

  1. Now, let’s make this into a nice, readable map that we could include in a report. Add at least four elements to your plot.
ggplot(data = tn_data_filter) +
  geom_sf(aes(fill = count, geometry = geometry)) +
  geom_sf(fill = NA, color = "white", size = 0.1) +
  scale_fill_viridis_c(option = "magma", name = "Percent of Teachers") +
  facet_wrap(~ race_ethnicity) +
  labs(
    title = "Teachers by Race/Ethnicity Across School Districts",
    subtitle = "White and Black or African American Teachers in Tennessee"
  ) +
  theme_void() +
  theme(
    legend.position = "bottom",
    strip.text = element_text(size = 12, face = "bold"),
    plot.title = element_text(size = 14, face = "bold")
  )
